Claimframe 0.4.1 adds vault sharing through CFText export/import, AI-assisted document intake,
and simpler entity naming, along with the improvements below. The previous public release was
0.3.2; 0.4.0 was not published. Renaming now replaces the current name; update saved queries
that refer to the old name. Capitalization is ignored, while punctuation and spaces matter.

- A compact workbench brings capture, review, recall, and navigation into a shared desktop shell.
- Saved Graph Recall views support incremental exploration and give the graph canvas more room.
- Recall autocomplete suggestions appear in an overlay without displacing the results.
- Graph Recall now exposes the same vocabulary inference controls as Assertions, including profile
  activation, Stored facts only, and profile details. Select an inferred relationship and expand
  **Explain inference** to inspect its rule and supporting premises in the graph selection drawer.

Linux DEB and RPM packages include the matching MCP server at `/usr/bin/claimframe-mcp`.
macOS desktop and MCP downloads require Apple Silicon; Windows downloads target x64.

### Before you upgrade

Close Claimframe and MCP sessions before installing. Back up your vault and retain the previous
installer. Upgrading an older vault requires confirmation and creates an automatic backup;
older application versions cannot open an upgraded vault. To recover, use the previous application
with the pre-upgrade backup, not the upgraded vault. CFText export carries current content, not full history,
and is not a replacement for a vault backup.
